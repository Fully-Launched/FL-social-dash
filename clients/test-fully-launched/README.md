# TEST CLIENT — not real, meant to be shared externally

"Fully Launched" is a made-up **self-serve** client, built specifically so
Tait can send a working client-portal link to a real person outside this
machine and confirm the whole review-gate flow actually works for someone
who isn't Tait. Displayed simply as "Fully Launched" (no "(TEST DATA)"
suffix, unlike the other two test clients) since this one is meant to look
and feel like the real thing to whoever's testing it — the fact that it's a
test is conveyed by context (they were sent the link specifically to test),
not by an in-app label.

Fictional business: a solo home-fitness coach. No real business, no real
interview happened here — everything in
`dashboards/clients/test-fully-launched/config.json` is fabricated for
testing.

Delete this folder and `dashboards/clients/test-fully-launched/` once
external testing is done, same as the other two test clients.
